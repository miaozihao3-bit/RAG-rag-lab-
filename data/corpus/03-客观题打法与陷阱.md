# 03 · 客观题打法与陷阱

> 客观题 50 分，40 题，目标 **40+**。这部分拼的不是知识量，是**题型手感 + 陷阱识别**。
> 每天 20 题，做完只记"错因类型"，不抄题干。

## 1. 30 分钟时间表

| 时间 | 动作 |
|---|---|
| 0–12' | 单选 15 题（约 45 秒/题），卡住标记 |
| 12–24' | 多选 10 题（约 70 秒/题），逐项判真伪 |
| 24–29' | 判断 15 题（约 20 秒/题），先找绝对化 |
| 29–30' | 回看标记题，只改有把握的 |

> 原则：**不在 1 分题上耗 3 分钟**。客观题多留 10 分钟，救不了后面 100 分。

## 2. 三套打法

### 单选：先排绝对化，再找定义匹配

1. 看到"一定 / 必然 / 完全 / 所有 / 只要…就 / 彻底 / 唯一 / 杜绝"→ 先打问号。
2. 排除跨领域选项（问语音，选项给像素/词向量；问 RAG，选项给 Function Calling）。
3. 剩下两个，选**能和考点定义逐字对上**的那个。
4. 实在不会：选"更具体、更机制化"的选项，不选口号。

### 多选：逐项判真伪，宁缺勿滥

- 四个选项**各自独立**判断，不要靠语感打包。
- 拿不准的一项，问自己："样卷里见过它吗？它属于这个考点吗？"
- 典型错项：**模型参数量**（不是 RAG 指标）、**Full Fine-tuning**（不是 PEFT）、**图像分类**（不是 NLP）、**掩码注意力**（不是编码器）、**网页对话**（不适合批量/审计）。
- 少选通常比错选安全；但"ABCD 全对"的治理题要敢全选。

### 判断：三个高频陷阱

| 陷阱 | 长什么样 | 例子 |
|---|---|---|
| **夸大** | 把"能缓解"写成"彻底解决"；"一定/必然/完全" | 多 Agent 数量增加一定更可靠更便宜（错） |
| **反因果** | 手段和结果对调；因果倒置 | Chinchilla 说优先加参数（错，应同比加数据） |
| **混概念** | 两个相近术语换一个字；状态码/模块/指标混淆 | 401 表示参数格式错误（错，401 是认证） |

补充两类：

- **绝对否定**："不包括 / 不需要 / 无法 / 不能"——先怀疑。
- **主体错位**：把 Harness 的能力记在模型头上；把框架的特性记在另一个框架头上。

## 3. 看到这些词就警惕

| 词 / 组合 | 为什么危险 |
|---|---|
| 一定、必然、完全、所有、唯一、彻底、杜绝、零误差 | 绝对化，大概率错 |
| 只要…就… | 充分条件被夸大 |
| 不需要、不包括、无法 | 绝对否定，先找反例 |
| 参数量、模型大小 | 常被拿来冒充"效果/评测指标" |
| 401 / 400 / 429 | 认证 / 格式 / 限流，年年混 |
| 编码器 / 解码器 | 掩码注意力只属解码器 |
| 准确率 / 召回率 | 一个看"报得准"，一个看"找得全" |
| 微调 / PEFT / LoRA | PEFT 不等于全参微调 |
| RAG / Function Calling / ReAct | 检索增强 ≠ 工具调用 ≠ 推理循环 |
| 静态批处理 / 连续批处理 | 等齐 vs 随时进出 |
| 量化 / 蒸馏 / 剪枝 | 三种不同的压缩手段 |
| 联邦学习 / 分布式学习 | 数据是否出本地 |
| 流式输出 / 投机解码 | 一个改"怎么吐"，一个改"怎么算" |

## 4. 术语一分钟卡（30 个）

| 术语 | 一句话 |
|---|---|
| MFCC | 语音常用声学特征，梅尔频率倒谱系数 |
| Word2Vec | 静态稠密词向量，可做类比运算，不看上下文 |
| CNN | 卷积提局部特征，池化降维，全连接分类 |
| Pooling | 降特征图空间维度；不引入非线性 |
| KV Cache | 缓存历史 token 的 K/V，随并发与长度线性涨 |
| PagedAttention | KV Cache 分页管理，消碎片，支撑动态请求 |
| Continuous Batching | token 级调度，请求随时进出，提高吞吐 |
| Speculative Decoding | 小模型起草，大模型并行校验；可预测文本才快 |
| TTFT | 首 token 延迟 |
| TPOT | 每 token 延迟 |
| LoRA | 低秩适配，PEFT 的一种 |
| RLHF | SFT → 奖励模型 → PPO，用人类偏好对齐 |
| RAG | 检索增强生成，先检索再生成 |
| Rerank | 对召回候选再排序，粗排 100 → 精排 Top5/10 |
| ReAct | 想 → 做 → 看，循环 |
| Function Calling | 用 Schema 描述工具，模型决定调用 |
| MCP | 把外部系统接成工具的标准协议 |
| Harness | 包裹模型的工程框架：指令、工具、上下文、循环、权限 |
| Human-in-the-loop | 低置信度转人工，阈值 + 留痕 |
| Semantic Cache | 语义相似命中缓存；要版本/TTL 防过期 |
| Model Routing | 简单问题走小模型，复杂问题走大模型 |
| Quantization | 降精度省显存/提吞吐，可能损精度 |
| OCR | 光学字符识别，读准数字/字段 |
| VLM | 视觉语言模型，理解语义/趋势 |
| Agent | 目标驱动、自主规划、调工具、有终止条件 |
| Workflow | 人写死步骤，自动执行 |
| Fine-tuning | 在预训练模型上继续训练 |
| Embedding | 把文本/图像映射成向量 |
| Hybrid Retrieval | 向量语义 + 关键词实体 |
| Hallucination | 幻觉，编造不存在的事实/引用 |

### 是非

> [!success]- 答案与一句解释
> 1. **B** vLLM 的标志组合。
> 2. **B** 池化只降空间维度；非线性靠激活。
> 3. **B** 跳 = 跳文档。
> 4. **C** 429 限流；400 格式；401 认证。
> 5. **C** 掩码注意力属解码器。
> 6. **C** 参数与数据同比。
> 7. **D** Full FT 是全参数微调。
> 8. **D** 参数量不是 RAG 指标。
> 9. **B** 目标驱动是智能体判据。
> 10. **B** 静态词向量。
> 11. **ABC** 参数量不是。
> 12. **ABCD** 四项都属治理。
> 13. **AC** B/D 反常识。
> 14. **ABCD** 四道闸门。
> 15. **ACD** 掩码注意力属解码器。
> 16. **对** 只改"怎么吐"。
> 17. **错** 高随机/短输出/分布不匹配时可能更慢。
> 18. **错** 绝对化，数量增加放大延迟与调试成本。
> 19. **错** 联邦学习数据不出本地。
> 20. **对** 连续批处理的核心特征。

## 6. 错因归类（只记这 6 类）

| 错因 | 表现 | 补救 |
|---|---|---|
| 没背定义 | 四个选项都不熟 | 回 [[02-考点地图与速记]] 对应层 |
| 绝对化没看出来 | 看到"一定"还选对 | 把题干里的绝对词圈出来 |
| 混概念 | 401/400、编码器/解码器 | 做一张对比表，抄 3 遍 |
| 主体错位 | 把 Harness 的功记给模型 | 问"这是谁的能力" |
| 多选漏选 | 只选最有把握的 | 逐项判真伪，别打包 |
| 多选错选 | 被"参数量/网页对话"骗 | 记住高频错项清单 |

## 7. 二刷规则

- 第一遍：限时 30 分钟，得分为主。
- 第二遍：只做错题 + 标记题，口头说"为什么错"。
- 第三遍：考前只看第 3 节的"危险词"和第 4 节的术语卡。
- 同一道题错两次 → 抄进 [[07-错题本与考前清单]]，写"错因类型"，不写长篇解析。
