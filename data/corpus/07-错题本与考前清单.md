### 错因类型只选 6 种

1. 没背定义
2. 绝对化没看出来
3. 混概念（401/400、编码器/解码器、PEFT/全参）
4. 主体错位（模型/Harness/框架）
5. 多选漏选
6. 多选错选（参数量、网页对话）

## 2. 高频易错 15 条（先背这些）

| # | 错误说法 | 正确口径 |
|---|---|---|
| 1 | 401 表示参数格式错误 | 401 认证失败；400 格式错误 |

| 7 | 静态批处理显存更省 | 静态按最长请求预留，反而浪费 |
| 8 | 投机解码任何场景都更快 | 高随机/短输出/分布不匹配时可能更慢 |
| 9 | RAG 评测看模型参数量 | 看召回率/忠实度/响应时间 |
| 10 | 联邦学习要集中数据 | 数据不出本地 |
| 11 | Word2Vec 随上下文变 | 静态词向量 |
| 12 | 流式输出减少参数量 | 只降 TTFT，改"怎么吐" |
| 13 | Agent 就是聊天机器人 | Agent 目标驱动、调工具、有终止条件 |
| 14 | 只加密就安全 | 入口分级脱敏 + 链路权限 + 出口审计 + 兜底 |
| 15 | 召回后再过滤权限就行 | 三路召回查询时就要带 ACL，重排再校验 |

## 7. 考场应急

| 情况 | 动作 |
|---|---|
| 软件打不开/环境异常 | 立刻举手叫监考，不要自己重装 |
| 端口冲突 | 换 `--port 8001`，同步改 base_url |
| 模型 API 失败 | 保留 Mock 业务 API；计划里标注"未获取"，**不编造** |
| 代码跑不通 | 先交能跑的最小版本 + README，再补 |
| 时间只剩 5 分钟 | 停止新功能，打包、检查目录、提交 |
| 忘记保存 | 每完成一题 `Ctrl+S`；答题纸每隔 10 分钟保存 |
