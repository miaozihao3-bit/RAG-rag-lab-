## 2. 第一题：AI 辅助代码修复（10 分）

### 2.1 题目要求逐条对照

| 要求 | 落地动作 |
|---|---|
| 密钥从环境变量读取 | `os.environ.get("LLM_API_KEY")`；缺失抛 `ConfigError` |
| 不得打印/写日志 | 不 `print(key)`；日志只记请求 ID/状态码 |
| 统一封装 HTTP 客户端 + 超时 | `LLMClient` + `requests.Session` + `timeout=15` |
| 依赖注入便于测试 | `ResearchAgent(client)`；测试传 fake client/session |
| 非 2xx / 结构错误抛明确异常 | `UpstreamError`；`resp.status_code` 检查；JSON 结构校验 |
| 保持"初稿-审校"两次调用 | `run()` 内两次 `chat()` |
| ResearchAgent 只编排 | 不写 HTTP 细节、不读环境变量 |

### 2.2 参考骨架

```python
import os
import requests

class ConfigError(RuntimeError):
    """配置缺失，例如环境变量未设置。"""

class UpstreamError(RuntimeError):
    """上游 HTTP 或响应结构异常。"""

class LLMClient:
    def __init__(self, base_url=None, api_key=None, timeout=15, session=None):
        self.base_url = (base_url or os.environ.get("LLM_BASE_URL", "")).rstrip("/")
        if not self.base_url:
            raise ConfigError("LLM_BASE_URL is not set")
        self.api_key = api_key or os.environ.get("LLM_API_KEY")
        if not self.api_key:
            raise ConfigError("LLM_API_KEY is not set")
        self.timeout = timeout
        self.session = session or requests.Session()

    def chat(self, prompt: str) -> str:
        try:
            resp = self.session.post(
                f"{self.base_url}/chat/completions",
                headers={"Authorization": f"Bearer {self.api_key}"},
                json={
                    "model": os.environ.get("LLM_MODEL", "default"),
                    "messages": [{"role": "user", "content": prompt}],
                },
                timeout=self.timeout,
            )
        except requests.Timeout as e:
            raise UpstreamError("upstream timeout") from e
        except requests.RequestException as e:
            raise UpstreamError(f"upstream request failed: {e}") from e

        if not (200 <= resp.status_code < 300):
            raise UpstreamError(f"HTTP {resp.status_code}: {resp.text[:200]}")

        try:
            data = resp.json()
            return data["choices"][0]["message"]["content"]
        except (ValueError, KeyError, IndexError, TypeError) as e:
            raise UpstreamError("malformed response") from e

class ResearchAgent:
    def __init__(self, client: LLMClient):
        self.client = client

    def run(self, topic: str) -> str:
        draft = self.client.chat(f"请写一段关于“{topic}”的初稿。")
        return self.client.chat(f"请审校以下初稿并给出终稿：\n{draft}")
```

### 2.3 两个测试点（至少）

```python
import pytest
import requests
from unittest.mock import Mock

def test_missing_api_key(monkeypatch):
    monkeypatch.delenv("LLM_API_KEY", raising=False)
    with pytest.raises(ConfigError):
        LLMClient(base_url="http://localhost:8000")

def test_non_2xx_raises():
    session = Mock()
    session.post.return_value = Mock(status_code=500, text="boom")
    client = LLMClient(base_url="http://localhost:8000", api_key="k", session=session)
    with pytest.raises(UpstreamError):
        client.chat("hi")

def test_malformed_response():
    session = Mock()
    session.post.return_value = Mock(status_code=200, text="ok", json=lambda: {"choices": []})
    client = LLMClient(base_url="http://localhost:8000", api_key="k", session=session)
    with pytest.raises(UpstreamError):
        client.chat("hi")

def test_timeout():
    session = Mock()
    session.post.side_effect = requests.Timeout()
    client = LLMClient(base_url="http://localhost:8000", api_key="k", session=session)
    with pytest.raises(UpstreamError):
        client.chat("hi")
```

> 测试不要求连真实模型；用 Mock 即可。**能跑 `pytest -q` 通过**比写得多更重要。

## 3. 第二题：AI 辅助程序设计（10 分）

### 3.1 缺陷定位

`UnicodeDecodeError` 的典型来源：

```python
# 错：把非 ASCII 文本按 ascii 编码/解码
text.encode("ascii")
text.encode("utf-8").decode("ascii")
```

emoji、日文汉字、控制字符都会触发。哈希场景的正确做法：**不要先 decode 成文本，直接对 UTF-8 bytes 做哈希**。

### 3.2 修复骨架（保持对外接口不变）

```python
import hashlib
import unicodedata

def calculate_hash(text: str) -> str:
    if not isinstance(text, str):
        raise TypeError("text must be str")
    normalized = unicodedata.normalize("NFC", text)
    return hashlib.sha256(normalized.encode("utf-8")).hexdigest()
```

如果原函数接受 `bytes`：

```python
def calculate_hash(data) -> str:
    if isinstance(data, str):
        data = unicodedata.normalize("NFC", data).encode("utf-8")
    return hashlib.sha256(data).hexdigest()
```

要点：UTF-8、不 decode 成 ascii、必要时 NFC 归一化、签名与返回类型不变。

### 3.3 两个测试

```python
import hashlib

def test_normal_input():
    assert calculate_hash("hello") == hashlib.sha256(b"hello").hexdigest()

def test_emoji_input():
    text = "😀🎉"
    assert calculate_hash(text) == hashlib.sha256(text.encode("utf-8")).hexdigest()
```

再补一个异常输入（控制字符/混合中日文）更稳：

```python
def test_mixed_unicode():
    text = "中文\x00日本語🙂"
    assert isinstance(calculate_hash(text), str)
```

### 4.2 三个 API 骨架（FastAPI）

```python
from typing import Optional
from fastapi import FastAPI
app = FastAPI(title="community-care-mock")

HOSPITALS = [
    {"id": "H1", "name": "社区卫生服务中心", "department": "骨科",
     "date": "2026-11-29", "period": "AM", "status": "full",
     "distance_km": 1.2, "insurance": True},
    {"id": "H2", "name": "区中心医院", "department": "骨科",
     "date": "2026-11-29", "period": "AM", "status": "available",
     "distance_km": 3.5, "insurance": True},
    {"id": "H3", "name": "市第二医院", "department": "骨科",
     "date": "2026-11-29", "period": "AM", "status": "suspended",
     "distance_km": 5.0, "insurance": False},
]

PHARMACIES = {
    "H2": [{"name": "医保定点药房A", "distance_km": 0.4, "insurance": True},
           {"name": "药房B", "distance_km": 1.1, "insurance": False}]
}

@app.get("/department_guide")
def department_guide(symptom: str, age: Optional[int] = None):
    dept = "骨科" if ("膝" in symptom or "关节" in symptom) else "全科"
    return {"department": dept,
            "materials": ["身份证", "医保卡", "既往病历", "近期影像"],
            "note": "分诊建议不替代医生诊断"}

@app.get("/hospital_search")
def hospital_search(department: str, date: str, period: str = "AM"):
    rows = [h for h in HOSPITALS if h["department"] == department
            and h["date"] == date and h["period"] == period]
    return {"date": date, "period": period, "hospitals": rows}

@app.get("/pharmacy_query")
def pharmacy_query(hospital_id: str):
    return {"hospital_id": hospital_id, "pharmacies": PHARMACIES.get(hospital_id, [])}
```

### 4.4 Agent 循环 + 四道终止闸门

```python
import json, time

MAX_TURNS = 8
TIMEOUT_S = 90

def run_agent(user_task, llm, tool_impls):
    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": user_task},
    ]
    seen = set()
    start = time.time()

    for turn in range(MAX_TURNS):
        if time.time() - start > TIMEOUT_S:
            return "执行超时，已停止并建议转人工。"

        resp = llm.chat(messages, tools=TOOLS)
        msg = resp["choices"][0]["message"]
        calls = msg.get("tool_calls") or []

        if not calls:
            return msg.get("content", "")

        messages.append(msg)
        for call in calls:
            name = call["function"]["name"]
            args = json.loads(call["function"]["arguments"])
            key = (name, json.dumps(args, sort_keys=True, ensure_ascii=False))

            if key in seen:
                return "检测到重复调用，已停止并转人工。"
            seen.add(key)

            try:
                result = tool_impls[name](**args)
            except Exception as e:
                result = {"error": str(e)}

            messages.append({
                "role": "tool",
                "tool_call_id": call["id"],
                "content": json.dumps(result, ensure_ascii=False),
            })

    return "达到最大轮次，已停止并转人工。"
```

四道闸门：**最大轮次 / 超时 / 目标达成（无 tool_calls 即收束）/ 重复调用检测**。

### 4.5 System Prompt（可直接改）

```text
你是“社区就医陪诊助手”。你只能依据工具/API 返回的真实数据回答，
不得虚构科室、号源、距离、天气、药房信息。

规则：
1. 先调用 department_guide 获取科室与携带材料；
2. 查询不少于 2 家医院的号源；
3. 优先推荐“有号、距离较近、医保定点”的医院，并说明理由；
4. 若首选医院已满或停诊，必须改选其他候选并说明原因；
5. 结合号源时段与地图耗时，倒推建议出发时间；
6. 就诊提醒必须包含 department_guide 返回的材料；
7. 若天气 API 返回高温/暴雨预警，增加防暑/防雨/错峰提醒；
8. 分诊建议不替代医生诊断；信息不足时明确说明并建议转人工；
9. 输出使用固定结构，不要编造缺失字段。
```

## 6. 常见翻车点

| 翻车 | 后果 | 预防 |
|---|---|---|
| Agent 直接读 `mock.json` | 违反"不得绕过 API"，扣分 | 只通过 HTTP / 函数调用 |
| Mock 只有正常数据 | 丢"异常决策"分 | 必备 `full` / `suspended` |
| 没有终止条件 | 死循环，交不出结果 | 四道闸门 |
| 没有调用记录 | 少交一件，扣分 | 边跑边填表 |
| 密钥硬编码/打印 | 安全项直接失分 | 环境变量 + 不日志 |
| 测试跑不过 | 测试项 0 分 | Mock 测试，不依赖真实 API |
| 没压缩/目录名错 | 可能无法评阅 | 最后 2 分钟检查压缩包 |
| 只写代码不写 Prompt | 少交一件 | Prompt 单独存 `prompt.md` |
